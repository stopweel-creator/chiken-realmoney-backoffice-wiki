# Адміністратор

## Основні обов'язки

- підтримувати стабільну роботу backoffice
- застосовувати задокументовані адміністративні дії лише за наявності підстав
- зберігати якість аудиту та операційну ясність
- оновлювати wiki та робочі сценарії, коли панель змінюється

## Щоденний чекліст

1. Переглянути картки огляду та стан системи перед роботою з таблицями.
2. Переконатися, що активна тема підходить для поточного типу задачі.
3. Перевірити недавню активність по виводах, адміністративних діях і раундах.
4. Перевірити активні та протерміновані раунди на аномалії.
5. Переглянути журнал адміністративних дій.
6. Перевірити конфігурацію Колеса фортуни, якщо є запит на зміну.
7. Ескалювати неясні кейси, що впливають на гроші.

## Рекомендації по темах

1. `Аврора` для загальної операційної роботи.
2. `Темна` для довгих аудиторських сесій.
3. `Опівнічна` коли потрібний сильніший візуальний акцент на подіях.

## Дозволені дії

- використовувати задокументовані примусові дії лише коли це обґрунтовано
- фіксувати причину дії в нотатці
- передавати фінансово чутливі питання фінансисту або бухгалтеру

## Не для цієї ролі

- ситуативні рішення по виплатах без узгодження з фінансистом
- незадокументовані зміни балансу
