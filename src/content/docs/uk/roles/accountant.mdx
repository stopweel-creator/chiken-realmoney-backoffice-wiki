# Бухгалтер

## Основні обов'язки

- звіряти фінансові записи через затверджені експорти й задокументовані подання
- перевіряти дані по виводах і пов'язаний контекст
- підтверджувати, що дії, які впливають на баланс, задокументовані

## Покроково: підготувати набір для звірки

1. Встановити потрібний діапазон дат.
2. Обрати тему, в якій щільні таблиці залишаються читабельними.
3. Відфільтрувати чергу або таблицю аудиту до потрібного обсягу.
4. Експортувати точний фрагмент для звірки.
5. Перевірити підсумки проти затвердженого бухгалтерського процесу.
6. Зафіксувати розбіжності для ескалації.

## Рекомендації по темах

- `Темна` є основною рекомендацією для довгих сесій звірки
- `Аврора` підходить для коротких перевірок
- `Опівнічна` варто використовувати лише якщо потрібні сильніші акценти статусів

## Важливі звички

- використовувати цільові експорти замість надто широких
- перевіряти нотатки до дій перед підтвердженням змін балансу
- працювати лише з задокументованими діапазонами дат і фільтрами статусів

## Не для цієї ролі

- технічні зміни конфігурації панелі
- незадокументовані ручні коригування
