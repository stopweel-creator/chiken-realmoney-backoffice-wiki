# Фінансист

## Основні обов'язки

- перевіряти готовність до виплат і роботу черги виводів
- перевіряти конфігурації винагород на бізнес-коректність
- підтверджувати, що суми й ваги Колеса фортуни відповідають затвердженому наміру

## Покроково: перевірити економіку колеса

1. Відкрити секцію Колеса фортуни.
2. Обрати тему з комфортним контрастом для поточної сесії.
3. Перевірити всі суми слотів.
4. Перевірити всі ваги.
5. Переглянути похідний розподіл шансів.
6. Переконатися, що бізнес-причина є в аудит-нотатці.
7. Схвалити або відхилити зміну через внутрішній процес.

## Рекомендації по темах

- `Темна` підходить для довгої перевірки політики
- `Опівнічна` корисна, коли бейджі виплат і статусів мають бути більш помітними
- `Аврора` підходить для короткої перевірки та координаційної роботи

## Покроково: перевірити activity по виплатах

1. Відкрити чергу виводів.
2. Застосувати потрібний діапазон дат.
3. Переглянути розподіл статусів і деталі запитів.
4. Експортувати точний набір для фінансової перевірки.
5. Ескалювати розбіжності між бізнес-політикою та станом черги.

## Не для цієї ролі

- технічні зміни доступу
- незадокументовані emergency actions
