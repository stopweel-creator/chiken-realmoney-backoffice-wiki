# Менеджер

## Основні обов'язки

- моніторити операційний стан системи
- перевіряти дії команди та виняткові кейси
- контролювати дотримання процесів
- координувати ескалації між операційною командою та фінансистами

## Щоденний чекліст

1. Переглянути підсумкові картки та стан черги.
2. Переконатися, що вибрана тема не заважає читати панель огляду.
3. Перевірити останні адміністративні дії за виконавцем і типом дії.
4. Переконатися, що великі конфігураційні зміни мають чіткі нотатки.
5. Запросити уточнення, якщо бізнес-причина відсутня.

## Рекомендації по темах

- `Аврора` для загального моніторингу
- `Темна` для довших сесій перевірки
- `Опівнічна` коли потрібний сильніший сигнал по попередженнях і змінах статусу

## Основні секції

- Журнал адміністративних дій
- Черга виводів
- Історія Колеса фортуни

## Не для цієї ролі

- прямий технічний troubleshooting внутрішніх систем
- зберігання інструкцій доступу в документації
