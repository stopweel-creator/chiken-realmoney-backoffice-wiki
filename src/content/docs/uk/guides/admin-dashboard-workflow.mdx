# Робота з панеллю огляду

1. Прочитати `Current State` і `Current CSV State`.
2. Переглянути картки `Overview`.
3. Переглянути блок `System Status`.
4. Переглянути блок `Recent Activity`.
5. Перейти в потрібний розділ через навігацію або рольові ярлики.
