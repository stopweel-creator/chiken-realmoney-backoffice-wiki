# Анімації та теми інтерфейсу

## Призначення

Backoffice використовує спільний шар анімацій і тем, щоб панель огляду, таблиці, бейджі й статусні блоки працювали узгоджено.

## Поточні теми

1. `aurora`
2. `dark`
3. `midnight`

## Перемикач теми

У toolbar адмінки є перемикач теми. Обрана тема зберігається через:

1. стан URL
2. локальні налаштування браузера
3. внутрішню навігацію адмінки
4. перенаправлення після адміністративних дій

## Правила анімації

1. Анімація має допомагати швидше зчитувати інтерфейс і бачити стан.
2. Пульсація подій має залишатися стриманою.
3. Фінансові таблиці мають бути читабельними в кожній темі.
4. Підтримка reduced motion має зберігатися.
