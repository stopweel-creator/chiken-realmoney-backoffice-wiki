# Подсказки

## Общие подсказки

- Перед изменениями читайте блок текущего состояния.
- Сначала применяйте фильтры, потом делайте export.
- Для всех действий, связанных с деньгами или ручным вмешательством, оставляйте краткую фактическую note.
- Предпочитайте сценарии своей роли ручным широким действиям.

## Подсказки по аудиту

- Фильтруйте по исполнителю, если проверяете конкретного оператора.
- Перед export audit CSV задавайте нужный диапазон дат.
- Проверяйте и список действий, и связанную детальную страницу пользователя или раунда.

## Подсказки по Колесу фортуны

- Анализируйте суммы и веса вместе, а не по отдельности.
- Сохраняйте конфигурацию только после проверки сводки шансов.
- В note используйте деловую формулировку, понятную менеджеру и финансисту.

## Подсказки по очереди выводов

- Перед эскалацией проверяйте текущий статус очереди.
- Для сверки используйте notes и exports, а не ручное копирование значений.

## Подсказки по документации

- Перед добавлением скриншота очищайте чувствительные поля.
- Обрезайте изображение до минимально полезной области интерфейса.
- Если процесс изменился, обновляйте и гайды, и страницы ролей.
