## Какие темы поддерживаются

- `Aurora` - основной яркий режим с живыми градиентами;
- `Dark` - спокойная тёмная тема;
- `Midnight` - тёмно-синяя контрастная тема для плотной работы с интерфейсом.

## Что делает motion layer

- плавно показывает основные секции после загрузки;
- добавляет мягкие hover-переходы;
- подчёркивает success/error события зелёными и красными акцентами;
- поддерживает единый визуальный ритм по всей панели.

## Правила использования

1. Меняйте тему под тип задачи, а не случайно.
2. Для плотных финансовых таблиц используйте тему с наилучшей читаемостью.
3. Если интерфейс нужен для демонстрации, выбирайте тему, которая не мешает считывать статусы.
4. Если используется reduced motion, не переопределяйте это поведение вручную.

## Важно

Тема не меняет права доступа, фильтры или данные. Она меняет только визуальный слой интерфейса.
