# Термины и типы

## Базовые термины

- `Actor` - обозначение оператора, выполнившего admin action.
- `Kind` - тип административного действия.
- `Status` - текущее состояние элемента очереди, раунда или процесса.
- `Close Reason` - причина закрытия раунда.
- `Current State` - активная комбинация фильтров и параметров отображения.

## Типы backoffice

### Типы admin actions

- `admin_set_balance`
- `admin_add_balance`
- `admin_round_finish`
- `admin_round_expire`
- `admin_round_lose`
- `admin_fortune_wheel_config`

### Частые статусы выводов

- `queued`
- `processing`
- `success`
- `failed`

### Частые исходы раундов

- `finished`
- `expired`
- `lost`
- `cashout`

## Типы документации

- `Guide` - пошаговая инструкция.
- `Role Playbook` - рабочие правила для конкретной роли.
- `Reference` - определения и стабильные описания.
- `Tips` - короткие практические рекомендации.
