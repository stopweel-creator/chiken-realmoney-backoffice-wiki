# Правила безопасных скриншотов

## Можно показывать

- структуру интерфейса;
- названия блоков и кнопок;
- безопасные вырезки без чувствительных значений;
- демонстрационные схемы и sanitized cutouts.

## Нельзя показывать

- реальные токены и ключи;
- внутренние URL и hostnames;
- реальные email пользователей;
- полные request id, payout id и другие чувствительные идентификаторы;
- любые значения, которые могут помочь в несанкционированном доступе.

## Практическое правило

Если без конкретного значения инструкция остаётся понятной, это значение не должно попадать на скриншот.
