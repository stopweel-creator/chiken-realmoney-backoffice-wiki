# Модули backoffice

## Верхний слой панели

Верхний слой панели - это точка входа во весь backoffice. Он включает:

- Section Navigation;
- Role Shortcuts;
- карточки Overview;
- карточки System Status;
- карточки Recent Activity.

## Users

Используется для проверки баланса пользователя, связанной активности и привязанных записей.

## Withdraw Queue

Используется для проверки заявок на вывод и их текущего состояния.

## Active Rounds

Используется для операционного контроля активных раундов.

## Expired Rounds

Используется для проверки раундов, закрытых логикой истечения срока.

## Rounds

Используется для более широкого исторического анализа раундов.

## Admin Actions

Используется для аудита административных действий с исполнителем, типом действия, note и временем.

## Колесо фортуны

Используется для настройки 7 слотов ежедневной награды, их сумм, весов, итогового распределения шансов и просмотра истории изменений конфигурации.

## Слой тем и анимации интерфейса

Используется для единообразных переходов, событийных подсветок, поведения градиентов и дальнейшего расширения темы по всему backoffice.
