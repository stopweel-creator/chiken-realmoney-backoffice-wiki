# Обзор админ-панели

## Назначение

Админ-панель - это рабочая поверхность для проверки пользователей, выводов, раундов, audit-действий и настройки Колеса фортуны.

## Верхние рабочие блоки

Перед таблицами расположены пять зон:

1. `Section Navigation` для перехода к нужному модулю.
2. `Role Shortcuts` для типовых представлений по ролям.
3. карточки `Overview` с количеством записей и суммами.
4. карточки `System Status` со статусом ledger, wiki, языка, темы и refresh.
5. карточки `Recent Activity` с последними событиями по выводам, раундам и административным действиям.

Используйте их в первую очередь. Это уменьшает риск работать в неверном состоянии панели.

## Анимации и визуальное поведение

Интерфейс использует общий motion layer:

1. крупные секции плавно появляются после загрузки;
2. интерактивные поверхности имеют мягкие hover-переходы;
3. success/error-события подчёркиваются сдержанными зелёными и красными акцентами;
4. визуальная система подготовлена под темы `aurora`, `dark` и `midnight`.

Анимация нужна для ускорения чтения интерфейса, а не для декоративного шума.

## Пошагово: как открыть правильное рабочее состояние

1. Откройте админ-панель.
2. Проверьте header summaries и `Current State`.
3. Применяйте только те фильтры, которые нужны для конкретной задачи.
4. Убедитесь, что overview cards соответствуют ожидаемому масштабу задачи.
5. Перед review и export проверьте page size и date range.
6. Если задача привязана к роли, используйте role shortcut.
7. Для пользователя, раунда, вывода или действия открывайте детальную страницу, а не работайте только из строки списка.
