## Пошагово: проверка заявки

1. Откройте раздел `Withdraw Queue`.
2. Найдите нужную заявку через search или фильтры.
3. Откройте детальную страницу вывода.
4. Проверьте текущий статус и связанный пользовательский контекст.
5. Зафиксируйте результат в процессе, который соответствует вашей роли.

## Пошагово: подготовка сверки

1. Установите правильный диапазон дат.
2. Примените только минимально необходимые фильтры.
3. Экспортируйте только данные за нужный период.
4. Сохраните export во внутреннем утверждённом месте.
5. Не отправляйте сырые exports по незащищённым каналам.

## Основные статусы

- `queued` - заявка ожидает обработки;
- `processing` - заявка находится в работе;
- `success` - заявка успешно завершена;
- `failed` - заявка требует проверки или исправления.

## Чего избегать

- принимать решение только по строке списка без детальной страницы;
- делиться скриншотами, которые показывают полные payout id или персональные данные;
- экспортировать слишком широкий набор данных, если достаточно точечного export.
