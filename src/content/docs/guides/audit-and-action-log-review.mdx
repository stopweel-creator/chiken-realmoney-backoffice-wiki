## Что показывает раздел аудита

Раздел аудита показывает административные действия с указанием:

- исполнителя (`actor`);
- типа действия (`kind`);
- суммы, если действие связано с деньгами;
- note;
- времени;
- связанных `user_id` и `round_id`.

## Пошагово: как проверять действие

1. Откройте раздел `Admin Actions`.
2. При необходимости задайте фильтр по исполнителю, типу действия, диапазон дат или поиск.
3. Найдите нужную запись.
4. Откройте детальную страницу действия.
5. Проверьте связанного пользователя и связанный раунд.
6. Только после этого делайте вывод по инциденту.

## Когда нужен export

Используйте export только тогда, когда нужна:

- сверка за период;
- передача данных в утверждённый внутренний контур;
- массовый анализ событий.

Если вам достаточно экрана и детальной страницы, не экспортируйте лишние данные.

## Чего избегать

- делать выводы по одной строке без детальной страницы;
- экспортировать широкий диапазон данных без необходимости;
- использовать audit без проверки текущих фильтров и `Current State`.
