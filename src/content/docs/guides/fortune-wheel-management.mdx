## Что настраивается

В системе есть 7 слотов ежедневного Колеса фортуны. Для каждого слота задаются:

- сумма выигрыша;
- вес;
- итоговый шанс, рассчитанный из веса.

## Пошагово: безопасное изменение конфигурации

1. Откройте блок Колеса фортуны.
2. Проверьте текущие суммы и веса.
3. Измените только нужные слоты.
4. Проверьте summary cards и распределение шансов.
5. Добавьте note с деловой причиной изменения.
6. Сохраните конфигурацию.
7. Убедитесь, что изменение попало в audit history.

## Что важно помнить

- Сервер определяет выигрыш по весам.
- Игра не выбирает приз самостоятельно.
- Клиент только визуально вращает колесо к уже выбранному сервером результату.

## Чего избегать

- менять только суммы без проверки весов;
- сохранять конфигурацию без note;
- вносить экспериментальные изменения прямо в рабочую конфигурацию без согласования.
