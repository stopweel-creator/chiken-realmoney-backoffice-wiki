# Accountant

## Main responsibilities

- Reconcile financial records using approved exports and documented views.
- Review withdrawal data and supporting context.
- Verify that balance-affecting actions are documented.

## Step-by-step: prepare a reconciliation set

1. Set the relevant date range.
2. Choose a theme that keeps dense rows readable.
3. Filter the queue or audit table to the required scope.
4. Export the exact slice required for reconciliation.
5. Cross-check totals against the approved accounting process.
6. Record discrepancies for escalation.

## Theme guidance

- `Dark` is the primary recommendation for long reconciliation sessions.
- `Aurora` is acceptable for shorter reviews.
- `Midnight` should be used only if stronger status emphasis helps the current task.

## Important habits

- use targeted exports instead of broad exports
- confirm action notes before accepting balance changes as valid
- work from documented date ranges and status filters

## Not for this role

- technical changes to panel configuration
- undocumented manual adjustments
