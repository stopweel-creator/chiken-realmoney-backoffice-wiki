# Administrator

## Main responsibilities

- Maintain stable operation of the backoffice.
- Apply documented administrative actions when justified.
- Preserve audit quality and operational clarity.
- Keep the wiki and workflows up to date when the panel changes.

## Daily checklist

1. Review the dashboard overview cards and system status before touching any table.
2. Confirm the active theme matches the task density and reading conditions.
3. Check recent activity for the newest withdrawal, admin action, and round update.
4. Check active rounds and expired rounds for anomalies.
5. Review the admin action log.
6. Confirm Wheel of Fortune configuration if a change request exists.
7. Escalate unclear money-impacting cases.

## Theme guidance

1. Use `Aurora` for general operational work.
2. Use `Dark` for long audit review sessions.
3. Use `Midnight` when stronger event emphasis helps with incident review.

## Allowed actions

- use documented force actions only when operationally justified
- document why the action happened
- route finance-sensitive questions to finance or accounting

## Not for this role

- ad hoc payout decisions without finance alignment
- undocumented balance changes
