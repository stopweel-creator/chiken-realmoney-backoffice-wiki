# Manager

## Main responsibilities

- Monitor operational health.
- Review team actions and exceptions.
- Confirm process compliance.
- Coordinate escalations between operations and finance.

## Daily checklist

1. Review summary cards and queue health.
2. Confirm the selected theme keeps the current dashboard readable.
3. Check recent admin actions by actor and kind.
4. Confirm that major configuration changes contain clear notes.
5. Request clarification when business reasons are missing.

## Theme guidance

- `Aurora` for high-level monitoring
- `Dark` for long management review
- `Midnight` for stronger signal around alerts and status changes

## Primary sections

- Admin Actions
- Withdraw Queue
- Wheel of Fortune history

## Not for this role

- direct technical troubleshooting of internal systems
- storing technical access instructions in documentation
