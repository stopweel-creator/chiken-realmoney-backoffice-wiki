# Interface Motion And Themes

## Purpose

The backoffice uses a shared motion and theme layer so that the dashboard, tables, badges, and status surfaces behave consistently.

2. `dark`

## Motion rules

1. Motion supports scanning and state awareness.
2. Event pulses must remain restrained.
3. Financial tables must stay readable under every theme.
4. Reduced motion support must remain available.
