# Действия с балансом

## Основные типы

- `admin_set_balance` - принудительная установка нового абсолютного значения баланса.
- `admin_add_balance` - ручное увеличение или уменьшение баланса на заданную дельту.

## Когда использовать

Используйте эти действия только тогда, когда бизнес-процесс требует подтверждённой ручной корректировки и это допускает ваша роль.

## Обязательные правила

1. Сначала откройте детальную страницу пользователя.
2. Убедитесь, что выбран правильный user.
3. Укажите точную причину в note.
4. После сохранения проверьте audit trail.

## Чего нельзя делать

- изменять баланс без note;
- работать только из списка без открытия детальной страницы;
- использовать ручную корректировку вместо штатного процесса, если штатный процесс доступен.
