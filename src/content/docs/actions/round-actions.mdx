# Действия с раундами

## Основные типы

- `admin_round_finish` - принудительно завершить active round с доступным settlement.
- `admin_round_expire` - принудительно закрыть раунд как истёкший.
- `admin_round_lose` - принудительно закрыть раунд как проигранный.

## Когда использовать

Только при подтверждённой операционной необходимости: зависший раунд, ручная обработка инцидента, корректировка состояния после эскалации.

## Порядок действий

1. Откройте детальную страницу раунда или пользователя.
2. Убедитесь, что это нужный active round.
3. Проверьте связанный контекст и историю действий.
4. Выберите правильный тип принудительного завершения.
5. Обязательно добавьте note.
6. После выполнения проверьте audit trail и статус раунда.

## Чего нельзя делать

- применять force action без проверки детальной страницы;
- использовать finish/expire/lose как обычный рабочий сценарий;
- оставлять пустую note.
