# Изменение конфигурации Колеса фортуны

## Что меняется

В backoffice настраиваются 7 слотов Колеса фортуны. Для каждого слота задаются:

- сумма;
- вес;
- итоговая доля вероятности.

## Безопасный порядок действий

1. Откройте блок Колеса фортуны.
2. Проверьте текущие суммы и веса.
3. Измените только те значения, которые действительно нужны.
4. Проверьте сводку шансов.
5. Добавьте note с деловой причиной изменения.
6. Сохраните конфигурацию.
7. Убедитесь, что запись попала в audit history.

## Важно

Клиент не определяет выигрыш сам. Сервер выбирает слот по весам, а игра только визуально прокручивает колесо к уже выбранному значению.
