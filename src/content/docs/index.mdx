# Wiki по backoffice Unstopable

<div class="hero-note">
Эта wiki - отдельный внутренний сайт документации для администраторов, менеджеров, бухгалтеров и финансовых специалистов. Здесь описано, как безопасно и последовательно работать с backoffice без публикации секретов, внутренних токенов, приватных URL и технических деталей, которые могли бы помочь злоумышленнику.
</div>

## Что есть в этой wiki

- описание модулей backoffice и их назначения;
- инструкции по ролям;
- пошаговые сценарии с безопасными вырезками интерфейса;
- правила безопасной работы с деньгами, аудитом, выводами и настройкой Колеса фортуны;
- рекомендации по использованию верхнего слоя панели: overview, system status, role shortcuts и recent activity.

## Чего здесь нет

- админских токенов, секретных ключей и приватных адресов сервисов;
- инструкций по обходу ограничений или получению несанкционированного доступа;
- debug-сценариев, которые ослабляют аудит;
- технических подсказок, пригодных для перебора, взлома или злоупотребления панелью.
