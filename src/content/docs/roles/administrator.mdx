# Администратор

## Зона ответственности

Администратор отвечает за рабочую целостность backoffice, ручные административные действия, настройку конфигураций и корректность audit trail.

## Основные задачи

- проверять состояние панели перед ручными действиями;
- выполнять approved admin actions;
- контролировать корректность note и audit history;
- сопровождать настройку Колеса фортуны;
- разбирать инциденты, связанные с active rounds.

## Что делать перед ручным действием

1. Открыть нужную детальную страницу.
2. Проверить `Current State`.
3. Убедиться, что выбран правильный пользователь, раунд или действие.
4. Записать деловую причину.
5. Только потом выполнять admin action.
