# Бухгалтер

## Зона ответственности

Бухгалтер отвечает за сверку данных, проверку очереди выводов, корректность export за период и сопоставление записей с утверждённым контуром учёта.

## Основные задачи

- проверять очередь выводов и статусы заявок;
- готовить точечные exports для сверки;
- использовать date range и минимально необходимые фильтры;
- работать только с теми данными, которые нужны для конкретного периода.

## Важно

Не используйте широкие exports, если достаточно точечной выборки. Не принимайте решения по строке списка без детальной страницы.
