# Финансовый специалист

## Зона ответственности

Финансовый специалист отвечает за корректность финансовых сценариев, проверку payout readiness, анализ Колеса фортуны и review административных действий, влияющих на деньги.

## Основные задачи

- проверять финансовые последствия admin actions;
- анализировать суммы и веса Колеса фортуны;
- сверять queue states и payout flow;
- использовать audit для подтверждения финансовой корректности изменений.

## Рабочий подход

1. Проверяйте current state и диапазон данных.
2. Сопоставляйте audit, user context и round context.
3. Для изменения конфигураций всегда требуйте понятную деловую причину.
