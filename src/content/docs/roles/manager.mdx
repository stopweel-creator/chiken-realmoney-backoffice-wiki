# Менеджер

## Зона ответственности

Менеджер отслеживает состояние процессов, использует панель огляду, фильтры и recent activity для оценки ситуации и эскалации проблем.

## Основные задачи

- отслеживать queue health и общую ситуацию в панели;
- использовать role shortcuts и overview cards;
- проверять recent activity перед эскалацией;
- координировать инциденты без несанкционированных ручных действий.

## Рабочий подход

1. Начинайте с верхнего слоя панели.
2. Проверяйте overview и system status.
3. Переходите в нужный раздел только после проверки контекста.
4. Если задача требует ручного финансового действия, передавайте её нужной роли.
